\## Project Title

\## Learner



Shaik Mohammad Shaheed



\## Overview



This project demonstrates the design, testing, and refinement of structured marketing prompts using ChatGPT.



The project covers six content types and six prompt engineering techniques:



\### Content Types



1\. Blog Posts

2\. LinkedIn Posts

3\. Email Campaigns

4\. Instagram Captions

5\. YouTube Video Scripts

6\. Product Descriptions



\### Prompt Engineering Techniques



1\. Zero-Shot Prompting

2\. One-Shot Prompting

3\. Few-Shot Prompting

4\. Role Prompting

5\. Style Transfer

6\. RGCCO Framework



\## Project Deliverables



\- `prompt\_library.md` — Optimized reusable prompt templates

\- `generated\_content.md` — Final outputs generated using the optimized prompts

\- `improvement\_report.md` — Before vs After quality comparison and prompt improvement analysis

\- `README.md` — Project overview and documentation



\## Quality Evaluation



The generated outputs were evaluated using four dimensions:



\- Relevance

\- Tone

\- Formatting

\- Length



Each dimension was scored from 1 to 5 for both the Before and After outputs.



\## Learning Outcome



Through this project, I practiced how to:



\- Give AI clear instructions

\- Define roles and goals

\- Provide relevant context

\- Apply prompt engineering techniques

\- Add constraints and output formats

\- Use examples to guide AI responses

\- Compare and improve AI-generated outputs

\- Build reusable prompt templates
