\## Task 1: Blog Post



\### Objective



Create a practical and professional blog post explaining why remote work can benefit businesses.



\### Before Prompt Issue



The original prompt was very simple: "Write a blog post about why remote work is good." It did not define the target audience, writing style, structure, or specific business-focused requirements. As a result, the output was useful but relatively general.



\### After Strategy



The optimized prompt used the \*\*RGCCO Framework\*\* to define the role, goal, context, constraints, and output format. \*\*Style Transfer\*\* was also added to guide the writing style using a reference text.



\### Improvement



The optimized output became more focused on B2B software managers and practical business benefits. It also used clear H1 and H2 headings, short paragraphs, active voice, and a final list of key takeaways. These constraints made the output more structured, relevant, and professional.



\## Task 2: LinkedIn Post



\### Objective



Create an authentic and professional LinkedIn post about learning prompt engineering.



\### Before Prompt Issue



The original prompt only asked for a LinkedIn post about learning prompt engineering. It did not specify the target audience, word limit, hook structure, emoji limit, or tone. The output was useful, but the prompt provided limited control over the final format and style.



\### After Strategy



The optimized prompt used \*\*Role Prompting\*\* by assigning the role of a professional LinkedIn content strategist. It also used \*\*Zero-Shot Prompting\*\*, meaning no examples were provided. Clear constraints were added for word count, hook, emojis, tone, and hashtags.



\### Improvement



The optimized output became more focused and structured for LinkedIn. It included a strong opening hook, practical learning points, a professional and authentic tone, and concise hashtags. The added constraints made the output more suitable for a professional LinkedIn audience.



\## Task 3: Email Campaign



\### Objective



Create a concise and persuasive sales email promoting the insulated water bottle.



\### Before Prompt Issue



The original prompt only asked ChatGPT to write a sales email for the new water bottle. It did not specify a clear role, email structure, customer-focused benefits, or formatting requirements. The output was useful but lacked stronger control over the email structure.



\### After Strategy



The optimized prompt used \*\*One-Shot Prompting\*\* by providing one example email structure and asking ChatGPT to create a new email using the same structure and tone. It also added constraints for conciseness, subject line, customer benefits, and professional tone.



\### Improvement



The optimized output included a clear subject line, concise body, customer-focused benefits, and a professional closing. The one example gave ChatGPT a clear structure to follow, making the final email more consistent and focused.



\## Task 4: Instagram Caption



\### Objective



Create a concise, warm, and engaging Instagram caption for a coffee cup image.



\### Before Prompt Issue



The original prompt only asked for a coffee caption. It did not provide examples, a specific tone, emoji guidance, or hashtag formatting requirements. The result was usable but offered limited control over the style and structure.



\### After Strategy



The optimized prompt used \*\*Few-Shot Prompting\*\* by providing three example captions. These examples demonstrated the desired style, structure, tone, and hashtag placement. Additional constraints were added for conciseness, emojis, tone, and hashtags.



\### Improvement



The optimized output followed the demonstrated warm and casual style while creating original wording. It used emojis naturally and placed the hashtags at the bottom. The examples gave ChatGPT a clearer pattern to follow, resulting in a more consistent Instagram-ready caption.



\## Task 5: YouTube Video Script



\### Objective



Create a beginner-friendly YouTube video script explaining how to start a business.



\### Before Prompt Issue



The original prompt asked for a YouTube script about starting a business but did not define a specific role, audience, output structure, or formatting requirements. Although the output contained useful information, it was presented as a long-form script rather than a structured visual-and-voiceover format.



\### After Strategy



The optimized prompt used \*\*Role Prompting\*\* by assigning the role of an experienced YouTube scriptwriter. It also applied the \*\*RGCCO Framework\*\* by defining the role, goal, context, constraints, and output format. The output was specifically required to use a two-column Markdown table.



\### Improvement



The optimized output became easier to use for video production because each row connects a visual suggestion with its corresponding voiceover. The content is organized into an opening hook, seven business-starting steps, a recap, and a call to action. The structured format makes the script clearer and more practical.



\## Task 6: Product Description



\### Objective



Create a professional and persuasive product description for a wireless mouse aimed at students, professionals, and everyday computer users.



\### Before Prompt Issue



The original prompt only asked ChatGPT to write a product description for a wireless mouse. It did not provide a target audience, feature-to-benefit structure, or specific requirements for the product description.



\### After Strategy



The optimized prompt used \*\*Few-Shot Prompting\*\* by providing three feature-and-benefit examples. It also applied \*\*Benefit Mapping\*\*, connecting each product feature to a clear customer benefit. Additional constraints were added for the title, number of features, tone, unsupported specifications, and call to action.



\### Improvement



The optimized output clearly connects product features with customer benefits. It includes five feature-benefit points, a concise product description, and a clear call to action. The examples helped establish the feature-to-benefit pattern, making the final product description more useful for potential customers.
